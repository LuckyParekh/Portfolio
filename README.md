# luckyparekh.com — Portfolio

Personal portfolio site for Lucky Parekh. Built with Next.js 14, Tailwind CSS, and Framer Motion.

## Getting Started

```bash
npm install
npm run dev      # localhost:3000
npm run build    # production build — must pass with zero errors
```

## Deployment

Push to GitHub and connect to Vercel. Set up automatic deployments from `main` branch.

## Before deploying

Replace these placeholders:
- `public/resume.pdf` — replace with real resume PDF
- Instagram URL in `components/Contact.tsx`
- SecureAuth GitHub repo URL in `components/Projects.tsx`
- PassAudit GitHub repo URL in `components/Projects.tsx`
- `/favicon.ico` — custom LP favicon
